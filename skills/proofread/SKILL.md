# Proofread

Proofread the target document for typos, spelling and grammar errors, wording improvements, and possible mathematical or logical errors.
If extension is not specified, prefer `.texlish`, then `.tex`.

By default, make changes that are clearly correct.
Ask about uncertain wording, mathematical, logical, factual, or style changes instead of silently applying them.
Summarize completed changes and proposed follow-up changes.

If the user asks not to edit, do not modify files; give line-specific feedback only.
Summarize definite issues first, then optional suggestions.
